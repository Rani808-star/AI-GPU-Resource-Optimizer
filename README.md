# AI GPU Resource Optimizer

A beginner-friendly Python prototype that monitors GPU resources and organizes AI jobs by priority.

## Features
- GPU utilization monitoring
- GPU memory monitoring
- AI job queue
- Job priority scheduling
- Estimated GPU cost
- Simple command-line dashboard

## How to Run
```bash
python main.py
```
